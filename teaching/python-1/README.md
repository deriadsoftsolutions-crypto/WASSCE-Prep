# Python 1: variables, data types and operations (STEM 3, 2 hours)

Based on Robotics for SHS Year 3 (learner book), Section 5, pages 84 to 90, and the Year 3 Teacher Manual, Section 5, Focal Area 1.

On the class site: Teacher > Lessons > **+ Add ready-made lesson** > Python for robots 1. This adds the lesson as a draft in unit 3.3.2, with the slides and starter files linked.

- `../../public/teaching/python-1/Python-1-Variables-Data-Types-Operations.pptx`: the 25-slide deck. The speaker notes hold the teaching script and timings.
- `../../public/teaching/python-1/python-1-starter-files.zip`: the starter files, zipped for download. Rebuild it with `python3 scripts/zip-teaching.py` after editing `vscode-files/`.
- `vscode-files/`: copy this folder to every learner computer before the lesson.
  - `00_hello_robot.py`: set-up check
  - `01_variables.py`: live coding
  - `02_robot_id.py`: Activity 5.2 (`02_robot_id_support.py` is a fill-in-the-blanks version)
  - `03_naming_game.py`: valid-or-not game
  - `04_types.py`: `type()` demo
  - `05_mission.py`: Activities 5.3 and 5.4
  - `06_operators.py`: predict, then run
- `answers/`: model answers, for the teacher only. They are not published on the site.

Learners without a working VS Code can use the class site: Learn > Python practice (`/python`). It has the same examples.
